# Changelog

## 1.0.0 (2026-11-27)

First release.

- Pick a color from anywhere on the screen with a global hotkey (Ctrl + Alt + C by default) and a zooming loupe. Arrow keys move the cursor by one pixel.
- Pick from an image: open it, drop it on the window, or paste it (screenshots too). Zoom and pan to the pixel you want.
- Copy as HEX, RGB, HSL, HSV, CMYK or OKLCH, automatically after each pick if you like.
- An editor with RGB, HSL and HSV sliders, a history of the last 48 colors and a palette of up to 96.
- Tray icon, start with Windows, always on top, and a single running copy.
- Appearance settings: dark, light or system theme, an accent color per tab or one for all, interface scale from 75% to 200%, a status bar, a background image with its opacity, the tray icon style and a fancy title.
